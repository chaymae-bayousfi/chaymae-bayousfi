## 👩‍💻 About Me

Hi, I'm **Chaymae** 👋 a Software Engineering student in my 3rd year of the Computer Science engineering cycle at **ENSA Khouribga**, and a student at **1337 Coding School** (42 Network), Morocco 🇲🇦.

I enjoy turning ideas into working products: from clean REST APIs and relational databases to interactive, real-time interfaces. My 1337 training in C/C++ gave me a solid base in algorithms and systems, and I now build full-stack applications while exploring DevOps and software architecture.

- 🔭 **Currently building:** *Subol*, a camping & bivouac platform (ft_transcendence team project)
- ⚡ **Recently built:** a real-time collaborative whiteboard with WebSocket and CRDT (Yjs)
- 🌱 **Learning & exploring:** CI/CD, Docker, microservices, software architecture
- 🎓 **Background:** ENSA Khouribga (engineering degree) × 1337 (project-based learning)
